Release v3.42.1: pre-dispatch recording actually starts. v3.42.0 recorded nothing.

## Fix (PR #353)

- **Before:** in v3.42.0 the pre-dispatch record was created after the sensor platforms were set up. The sensor setup therefore found no record to subscribe to pre-dispatch runs, so no run was ingested, and `Predispatch Binding Constraints` showed no `pd_observations` or `pd_history_days`. Seen on a live install within minutes of upgrading.
- **Now:** the record is created and loaded before the platforms are set up. A test pins the order.

## Upgrade notes

- **Unchanged:** entities and values.
- **Recording:** pre-dispatch recording starts with the first run after the upgrade.
