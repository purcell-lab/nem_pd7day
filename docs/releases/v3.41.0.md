Release v3.41.0: stage 1 of the forecast timeline plan (#333, #335). Every price source is now fetched once for all entries and carries an identity for later stages to cache on. Published values are unchanged.

## One TradingIS fetch for every entry (PR #350)

- **Before:** each config entry fetched TradingIS itself, so a five-region install made five directory listings and five downloads of the same zip every half hour.
- **Now:** one shared service fetches the listing and the zip once, parses every region once, and records each region into its own entry's calibration store. A five-entry install makes 2 requests a half hour instead of 10.
- **Records unchanged:** the observations recorded are identical: same price, same `actual_source: tradingis`.
- **Timer:** it runs at :02 and :32 NEM time whatever time zone Home Assistant uses; the old timer used Home Assistant's local time.

## P5MIN for every region (PR #349)

- **RRP kept:** the P5MIN parse keeps each region's RRP beside its ROP. Stage 4's timeline will publish it raw for the next hour.
- **Fetched regardless of listeners:** P5MIN is fetched after every dispatch poll once any entry is set up, not only while a DUID sensor listens. Every region's zone sensors already kept it fetching in practice.

## Typed sources (PR #351)

- **New module:** `price_sources.py`, a domain module, gives each source an identity `(kind, source, run_at)`. That covers the dispatch snapshot (each region's RRP and ROP), the P5MIN run, the pre-dispatch snapshot and a PD7DAY run.
- **Dispatch RRP:** the DispatchIS parse keeps each region's RRP too.
- **Import layers:** `predispatch_client` and `constraint_client` join the services layer of the import contracts, and `price_sources`, `predispatch_local_price`, `zones` and `load_points` the domain layer. There are no new violations.

## Upgrade notes

- **Unchanged:** entities, values, recorded observations and requirements.
- **NEMWEB load:** TradingIS requests drop by 80% on a five-entry install. P5MIN is fetched for every region; that cost was already being paid by the zone sensors.
