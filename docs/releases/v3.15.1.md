Release v3.15.1. The PRCER export sensor prices its spot component the way the library prices every other export.

## The extension export omitted the loss factors

`aemo_to_tariff.spot_to_feed_in_tariff` multiplies spot by its default distribution, metering and market loss factors before the network module adds the credit or charge. The routing wrapper added in v3.15.0 handed an extension export the raw spot, so the Powercor PRCER export sensor sat about 9 per cent off what the same spot gives on a library-priced export; the import side already passed the factors. Measured on the live install at 15:06 AEST on 20 September with VIC1 at about -21.7 $/MWh, it published -0.03172 $/kWh against a correct -0.03372 (PR #174).

The wrapper now passes the same factors the import path does, and the extension export test asserts the library's composition and rejects the raw-spot one.

## What to expect on deploy

- The PRCER export sensor moves by the loss-factor multiple on its spot component, about 9 per cent of spot. Nothing else moves.
