Release v3.35.1. The options form opens again.

## Fix (PR #291)

Since v3.33.0, **Configure** on the integration failed to open, and the options flow API returned HTTP 400.

- **Cause:** HA's number selector only accepts a step of `any` or one of at least 0.001. The loss factor field used 0.0001, so building the form raised an error before it was shown.
- **Fix:** the step is now `any`, which still takes four decimals such as 1.0272.
- **Test:** a new test checks every number selector in the form against that rule.

- **Entities and values:** unchanged.
- **Requirements:** unchanged.
