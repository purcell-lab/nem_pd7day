Release v3.33.0. A loss factor setting for every tariff price; one DUID local price sensor per DUID, with a bundled DUID catalogue for the options dropdown, the map and each region's most constrained units.

## Loss factor option (PR #280)

Every tariff price scaled spot by the library's Energex defaults, DLF 1.05905 × MLF 1.0154 × market 1.0154 = **1.0919**, with no way to change them. Settled Amber prices on an Energex site follow **RRP × 1.0272**, so the spot part of both import and export forecasts was about 6.3% high.

- **New option**, "Loss factor (spot multiplier)", from 0.9 to 1.3: one combined factor for every import and export tariff price. Empty keeps the defaults, and default prices do not move.
- **The options form** shows the library's factor and the one in Amber Express's current settled feed-in interval, as a suggestion. It is never applied by itself.
- **Attributes:** the tariff sensors publish the factor in use, and `loss_factor_source` (`option` or `library_default`).

## One DUID sensor, and the DUID catalogue (PR #281, #279)

- **One sensor per DUID**, `sensor.nem_pd7day_{region}_{duid}_local_price_adjustment`, in the device's Diagnostic section:
  - **State:** the dispatch adjustment.
  - **Forecast:** the P5MIN `forecast` as attributes, with its own status and age.
  - **Local price:** `local_price` and the ROP used.
- **Catalogue:** `duid_catalogue.json`, built before each release from AEMO's registration data, Open Electricity's public facility files and two weeks of dispatch, gives each DUID its region, station, fuel and coordinates.
  - **Options:** the DUID field is a dropdown of the region's DUIDs, most constrained first; any DUID can still be typed.
  - **Presets:** each region's five most constrained DUIDs are added as disabled sensors. Enable one and it updates; P5MIN is fetched only while a DUID sensor is enabled.
  - **Map:** catalogued DUIDs publish `latitude` and `longitude`, `station`, `fuel` and `duid_region`.
  - **Local price region:** the local price uses the DUID's own region's ROP.
- **`age_seconds`** runs from the interval's start. AEMO publishes the file while its interval runs, so a current reading was negative.
- **DUID check:** DUIDs with `-`, `#` or `/` (`BARRON-1`, `W/HOE#1`) are accepted.

## Upgrade notes

- **DUID sensors:** each chosen DUID's `..._local_price_adjustment_forecast` and `..._local_price` sensors from 3.32 are removed. The `..._local_price_adjustment` sensor keeps its entity id and history, and carries both as attributes. The local price diagnostic option is gone.
- **Presets:** each entry gains up to five disabled DUID sensors.
- **Loss factor:** set it in the options to change tariff prices; until then they are unchanged.
- **Requirements:** unchanged (`aemo-to-tariff` 0.7.28).

## Minor

New options, attributes and sensors, so a minor version. The suite goes from 1848 to 1886 tests.
