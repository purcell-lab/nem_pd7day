Release v3.31.1. HACS can install the integration again. The code is the same as 3.31.0.

## HACS installs from the release's files, not the zip (PR #273)

Since 24 Oct 2026, GitHub's release-download redirect carries a Content-Security-Policy header of about 9.2 KB. Home Assistant's HTTP client reads at most 8,190 bytes of headers, so every HACS download of `nem_pd7day.zip` failed:

- HACS reported "Downloading purcell-lab/nem_pd7day with version v3.31.0 failed with (Could not download, see log for details)";
- the log reads "Got more than 8190 bytes when reading";
- it affected every version, not just the latest; v3.30.0 failed the same way.

`hacs.json` now sets `zip_release: false`. HACS fetches the tag's `custom_components/nem_pd7day` files through the GitHub API instead. The zip is still attached to each release for manual installs.

## Upgrade notes

- **Install:** use HACS as usual. If it does not offer 3.31.1 yet, use **Update information** on the repository first. HACS reads `hacs.json` from the version being installed, so v3.31.0 and earlier still try the zip and fail; install 3.31.1 or later.
- **Code:** unchanged from 3.31.0. Upgrading from 3.30.0 or earlier brings in 3.31.0's day 2-7 changes; see `docs/releases/v3.31.0.md`.
- **Attributes and values:** unchanged.
- **Requirements:** unchanged (`aemo-to-tariff` 0.7.28).
