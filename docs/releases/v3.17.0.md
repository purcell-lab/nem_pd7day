Adds a separate, experimental QLD1 scarcity-premium sensor with a 30-minute `forecast` attribute containing `time` and `value` fields in $/kWh for HAEO-compatible additive pricing.

The heuristic uses a complete 07:00–10:00 NEM morning-price window to calculate a capped, non-negative premium for 10:00–14:00. Missing required observations produce an unavailable signal rather than an invented premium. Outside the active window, the premium is zero.

This is an experimental heuristic, not a calibrated expected forecast residual. Existing price sensors and HAEO configuration are unchanged. Connecting the premium to HAEO requires a separate activation decision.

Implements PR #179.
