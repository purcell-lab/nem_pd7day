Release v3.44.0: the price timeline, stage 4 of the forecast timeline plan (#333, #338). Each region publishes one timeline: the current dispatch interval, then P5MIN's 5-minute prices for the next hour, pre-dispatch to the end of the next trading day, and calibrated PD7DAY to day 7. No existing attribute changes.

## The timeline (PR #355)

- **Sources, in order:** each source covers what the one before it does not.
  - `dispatch`: the RRP being paid now.
  - `p5min`: raw RRP, 5-minute.
  - `predispatch`: 30-minute RRP. It is served as `calibrated_source: passthrough` until stage 3b fits a pre-dispatch calibration on the observations stage 3a is recording.
  - `pd7day`: calibrated, with its band.
- **Splits:** a half hour the source before covers in part is split where that source ends, so no minute is repeated or skipped.
- **Staleness:** a stale source drops out and the next fills its span. P5MIN goes stale past 15 minutes, pre-dispatch past 75. `timeline_sources` records each source's coverage, run and age.
- **Each point:** `time`, `nemtime`, `value` ($/kWh), `source`, `calibrated_source`, `p10`, `p50`, `p90` and `resolution_minutes`.
- **Where it is published:**
  - a new **`Price Timeline`** diagnostic sensor per region. Its state is the timeline's value now; its attributes are `timeline` and `timeline_sources`.
  - a `timeline` attribute on the spot forecast sensor.

  Neither list is saved to the recorder.
- **What is unchanged:** the spot forecast sensor's `forecast`, and the tariff and day 2-7 sensors, stay PD7DAY's alone. Stage 5 (#339) moves them onto the timeline.
- **Cost:** built once per region per source change and 5-minute interval, in the shared forecast hub, from the calibrated forecast the spot sensor already holds. That is 0.02 ms per write for the new sensor, and 0.05 to 0.06 ms for the spot forecast sensor's attributes.

## Upgrade notes

- **New entity:** `sensor.nem_pd7day_<region>_price_timeline`, diagnostic.
- **New attribute:** `timeline` on `sensor.nem_pd7day_<region>_nem_spot_price_forecast`.
- **Golden snapshots:** regenerated. Only the new sensor and the new attribute differ in all 15 scenarios.
- **Requirements:** unchanged.
