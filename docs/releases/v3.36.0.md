Release v3.36.0. Local price forecasts to the end of the next trading day, from AEMO's 30-minute pre-dispatch, on the DUID and node sensors; node sensors also publish their local price adjustment. Stage 2 of #285.

## Pre-dispatch local prices (PR #293)

Each PredispatchIS run carries every constrained DUID's local price adjustment for each 30-minute period, to the end of the next trading day. The integration already reads that file every half hour, so this adds no requests.

- **DUID sensors:** `predispatch_forecast` lists the adjustments in $/kWh, by period start.
  - **Zero by omission:** a period without a row in a fresh run is 0, counted in `predispatch_intervals_inferred_zero`.
  - **No points:** a run older than 75 minutes, or one without the table.
- **Node sensors:**
  - `adjustment_mwh` and `adjustment_status`: the published dispatch adjustment of the node's DUIDs, 0 when a fresh file has no row for them.
  - `local_price`: ROP × MLF + adjustment. The state stays the static node price.
  - `predispatch_forecast`: RRP × MLF + adjustment. Pre-dispatch publishes RRP, not ROP.
- **Why published values:** rebuilding the adjustments from AEMO's constraint factors was tested, and reproduced 52 of 76 units on a live interval. Constraint versions newer than the last monthly archive have no factors yet, and the full factor set is 4.3 MB of JSON. See #287.
